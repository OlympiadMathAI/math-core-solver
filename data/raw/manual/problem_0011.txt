ID: 0011

SOURCE: IMO Shortlist

YEAR: 2010

TOPIC: Combinatorics

SUBTOPICS: Chessboard, Structural Counting

STATEMENT:
Place $2500$ kings on a $100\times100$ chessboard so that

(i) no king attacks another king, meaning that no two occupied squares share a vertex;

(ii) every row and every column contains exactly $25$ kings.

Find the number of such arrangements. Arrangements related by rotation or reflection are counted as different.

SOLUTION 1:
There are exactly
\[
\boxed{2}
\]
such arrangements.

Divide the board into $2500$ disjoint $2\times2$ blocks. A block contains at most one king, because any two squares in the same block share a vertex. Since there are exactly $2500$ kings, every block contains exactly one king.

For each block, record whether its king lies in the top or bottom row of the block, writing $T$ or $B$, and whether it lies in the left or right column, writing $L$ or $R$. Thus every block has one of the four types
\[
TL,TR,BL,BR.
\]
We now work with the resulting $50\times50$ array of blocks.

Two propagation rules follow from the nonattacking condition:

- if block $(i,j)$ is a $B$-block, then $(i+1,j)$ is also a $B$-block; similarly, a $T$-block forces the block above it to be a $T$-block;

- if block $(i,j)$ is an $L$-block, then $(i,j-1)$ is also an $L$-block; similarly, an $R$-block forces the block to its right to be an $R$-block.

Every block-column contains exactly $25$ $L$-blocks and $25$ $R$-blocks, because the two original columns represented by it each contain $25$ kings. Similarly, every block-row contains exactly $25$ $T$-blocks and $25$ $B$-blocks.

Look at the top block-row. Its $25$ $B$-blocks propagate downward, so they determine $25$ entire $B$-columns. Since the total number of $B$-blocks is $25\cdot50$, all remaining columns are entirely $T$-columns. Thus there are exactly $25$ $T$-columns and $25$ $B$-columns. In the same way, there are exactly $25$ $L$-rows and $25$ $R$-rows.

Because both kinds of columns occur, somewhere two neighboring columns have different types.

\textbf{Case 1.} Suppose column $j$ is a $T$-column and column $j+1$ is a $B$-column. If row $i$ is an $L$-row, then block $(i,j+1)$ is of type $BL$. To avoid a diagonal attack, block $(i+1,j)$ cannot be $TR$. Since column $j$ is a $T$-column, block $(i+1,j)$ must therefore be $TL$, so row $i+1$ is also an $L$-row.

Starting from the topmost $L$-row, all rows below it are $L$-rows. There are exactly $25$ such rows, hence rows $1,\ldots,25$ are $R$-rows and rows $26,\ldots,50$ are $L$-rows. Applying the same argument with rows and columns interchanged to the boundary between rows $25$ and $26$, we conclude that columns $1,\ldots,25$ are $T$-columns and columns $26,\ldots,50$ are $B$-columns. This determines one arrangement uniquely.

\textbf{Case 2.} Suppose instead that column $j$ is a $B$-column and column $j+1$ is a $T$-column. The symmetric argument gives rows $1,\ldots,25$ as $L$-rows and the remaining rows as $R$-rows, while columns $1,\ldots,25$ are $B$-columns and the remaining columns are $T$-columns. This determines exactly one further arrangement.

Both arrangements satisfy the conditions, and no other pattern is possible. Hence the answer is $2$.
