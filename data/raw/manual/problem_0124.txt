ID: 0124

SOURCE: IMO Shortlist

YEAR: 2014

TOPIC: Combinatorics

SUBTOPICS: Rook Placements, Permutations, Pigeonhole Principle, Extremal Construction

STATEMENT:
Let $n\ge2$. An $n\times n$ chessboard contains $n$ rooks in a happy configuration if every row and every column contains exactly one rook. Find the greatest positive integer $k$ such that every happy configuration contains a $k\times k$ square of unit cells containing no rook.

SOLUTION 1:
The answer is
\[
\boxed{\left\lfloor\sqrt{n-1}\right\rfloor}.
\]

For a positive integer $\ell$, we prove the following two statements:

\begin{enumerate}
\item if $n>\ell^2$, then every happy configuration contains an empty $\ell\times\ell$ square;
\item if $n\le\ell^2$, then there is a happy configuration containing no empty $\ell\times\ell$ square.
\end{enumerate}

\textbf{1. The guaranteed empty square.}
Assume $n>\ell^2$. Some row has its rook in the leftmost column; call this row $R$. Choose any $\ell$ consecutive rows containing $R$. Their union contains exactly $\ell$ rooks.

Delete from these rows the leftmost $n-\ell^2$ columns. Since $n-\ell^2\ge1$, the rook in row $R$ is deleted. The remaining rectangle has dimensions $\ell\times\ell^2$ and contains at most $\ell-1$ rooks. Partition it into $\ell$ disjoint squares of size $\ell\times\ell$. At least one of these squares contains no rook.

\textbf{2. A construction with no empty square.}
First take $n=\ell^2$. Number the rows and columns by
\[
0,1,\ldots,\ell^2-1.
\]
For every $0\le i,j<\ell$, place a rook in the cell
\[
(i\ell+j,\;j\ell+i).
\tag{1}
\]
Every row and every column occurs exactly once in (1), so the configuration is happy.

We show that every $\ell\times\ell$ square contains a rook. Consider any $\ell$ consecutive rows. Let the first row be
\[
p\ell+q,
\qquad 0\le p,q<\ell.
\]
The rook columns in these rows, written in increasing order, are
\[
p+1,\ \ell+p+1,\ \ldots,\ (q-1)\ell+p+1,
\quad
q\ell+p,\ (q+1)\ell+p,\ \ldots,\ (\ell-1)\ell+p,
\tag{2}
\]
with either part omitted when empty. The first number in (2) is at most $\ell-1$, the last is at least $\ell^2-\ell$, and the gap between consecutive numbers is at most $\ell$. Therefore every set of $\ell$ consecutive columns contains at least one of the columns in (2). Hence every $\ell\times\ell$ square contains a rook.

Now let $n<\ell^2$. Start with the above $\ell^2\times\ell^2$ construction, delete the bottom $\ell^2-n$ rows and the rightmost $\ell^2-n$ columns, and retain the surviving rooks. Any $\ell\times\ell$ square in the remaining $n\times n$ board was already such a square in the original board, so it still contains a surviving rook.

Some rows and columns may now be empty. The number of empty rows equals the number of empty columns, because the surviving rooks occupy distinct rows and distinct columns. Pair the empty rows with the empty columns and place one rook at every paired intersection. The resulting configuration is happy and still has no empty $\ell\times\ell$ square.

Thus an empty $\ell\times\ell$ square is guaranteed exactly when $\ell^2<n$. The largest such integer is
\[
\left\lfloor\sqrt{n-1}\right\rfloor.
\]
