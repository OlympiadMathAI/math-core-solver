ID: 0005

SOURCE: IMO Shortlist

YEAR: 2010

TOPIC: Algebra

SUBTOPICS: Functional Equations, Rational Numbers

STATEMENT:
Let $\mathbb{Q}_{>0}$ be the set of positive rational numbers. Determine all functions
\[
f:\mathbb{Q}_{>0}\to\mathbb{Q}_{>0}
\]
such that
\[
f\bigl(f(x)^2y\bigr)=x^3f(xy)
\tag{1}
\]
for all $x,y\in\mathbb{Q}_{>0}$.

SOLUTION 1:
We will prove that the unique solution is
\[
\boxed{f(x)=\frac1x}.
\]
Putting $y=1$ in (1), we obtain
\[
f(f(x)^2)=x^3f(x).
\tag{2}
\]
If $f(x)=f(y)$, then (2) gives
\[
x^3=\frac{f(f(x)^2)}{f(x)}
=\frac{f(f(y)^2)}{f(y)}=y^3,
\]
so $x=y$. Hence $f$ is injective.

Replace $x$ by $xy$ in (2). Using (1) twice, the second time with the pair $(y,f(x)^2)$, we get
\[
\begin{aligned}
f(f(xy)^2)
&=(xy)^3f(xy)\\
&=y^3 f(f(x)^2y)\\
&=f(f(x)^2f(y)^2).
\end{aligned}
\]
Injectivity implies
\[
f(xy)^2=f(x)^2f(y)^2.
\]
All values are positive, so
\[
f(xy)=f(x)f(y).
\tag{3}
\]
Thus $f$ is multiplicative. In particular, $f(1)=1$ and
\[
f(x^m)=f(x)^m
\]
for every integer $m$ for which the expression is defined.

Using multiplicativity in (1), we obtain
\[
f(f(x))^2f(y)=x^3f(x)f(y),
\]
and therefore
\[
f(f(x))=\sqrt{x^3f(x)}.
\tag{4}
\]
Define
\[
g(x)=xf(x).
\]
Then, by (3) and (4),
\[
\begin{aligned}
g(g(x))
&=xf(x)\,f(xf(x))\\
&=xf(x)^2f(f(x))\\
&=xf(x)^2\sqrt{x^3f(x)}\\
&=(xf(x))^{5/2}=g(x)^{5/2}.
\end{aligned}
\]
Iteration yields
\[
g^{\circ(n+1)}(x)=g(x)^{(5/2)^n}
\tag{5}
\]
for every positive integer $n$.

Fix $x$. The left-hand side of (5) is rational for every $n$, so the same is true of the right-hand side. Suppose $g(x)\ne 1$, and write its prime factorization as
\[
g(x)=p_1^{\alpha_1}\cdots p_r^{\alpha_r},
\]
where the $\alpha_i$ are nonzero integers. Then
\[
g(x)^{(5/2)^n}
=p_1^{(5/2)^n\alpha_1}\cdots p_r^{(5/2)^n\alpha_r}.
\]
For this number to be rational, every exponent must be an integer. This is impossible for sufficiently large $n$, because $2^n$ cannot divide the fixed nonzero integer $\alpha_1$. Hence $g(x)=1$ for every $x$, and therefore
\[
f(x)=\frac1x.
\]
Finally,
\[
f(f(x)^2y)
=\frac1{(1/x)^2y}
=\frac{x^2}{y}
=x^3\frac1{xy}
=x^3f(xy),
\]
so this function indeed satisfies (1).
