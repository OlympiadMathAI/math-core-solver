ID: 0274

SOURCE: IMO Shortlist

YEAR: 2019

TOPIC: Combinatorics

SUBTOPICS: Binomial Coefficients, Induction, Multisets, Unimodality

STATEMENT:
The infinite sequence $a_0,a_1,a_2,\ldots$ of not necessarily distinct integers satisfies
\[
0\le a_i\le i
\qquad(i\ge0)
\]
and
\[
\binom{k}{a_0}+\binom{k}{a_1}+\cdots+\binom{k}{a_k}=2^k
\qquad(k\ge0).
\]
Prove that every nonnegative integer occurs in the sequence; that is, for every $N\ge0$ there is an index $i\ge0$ such that $a_i=N$.

SOLUTION 1:
We prove the following stronger description by induction on $k$:

For some integer $\ell\ge0$ satisfying $2\ell\le k+1$, the multiset
\[
\{a_0,a_1,\ldots,a_k\}
\]
is
\[
\{0,1,\ldots,\ell-1\}\mathbin{\uplus}
\{0,1,\ldots,k-\ell\},
\tag{1}
\]
where $\uplus$ denotes multiset union.

For $k=0$, the given inequalities force $a_0=0$, so (1) holds with $\ell=0$.

Assume that (1) holds for $k=m$. Thus the already known terms contribute
\[
2\sum_{r=0}^{\ell-1}\binom{m+1}{r}
+
\sum_{r=\ell}^{m-\ell}\binom{m+1}{r}
\]
to the equation for $k=m+1$. Comparing this with
\[
\sum_{r=0}^{m+1}\binom{m+1}{r}=2^{m+1}
\]
and using
\[
\binom{m+1}{r}=\binom{m+1}{m+1-r},
\]
we obtain
\[
\binom{m+1}{a_{m+1}}=\binom{m+1}{\ell}.
\tag{2}
\]
The binomial coefficients in a fixed row strictly increase up to the middle and then decrease symmetrically. Since $0\le a_{m+1}\le m+1$, equation (2) gives
\[
a_{m+1}=\ell
\qquad\text{or}\qquad
a_{m+1}=m+1-\ell.
\]
In the second case, the second interval in (1) is extended by one term. In the first case, if the two alternatives are distinct then the old second interval already contains $\ell$, so the new copy of $\ell$ gives the same description with $\ell$ replaced by $\ell+1$. If the alternatives coincide, then $m+1=2\ell$ and the same description remains valid with $\ell$ unchanged. Thus (1) also holds for $m+1$.

Now take any $N\ge0$ and apply (1) with $k=2N$. Since $2\ell\le2N+1$, we have
\[
2N-\ell\ge N.
\]
Therefore the second interval in (1) contains $N$, so one of
\[
a_0,a_1,\ldots,a_{2N}
\]
equals $N$. Hence every nonnegative integer occurs.
